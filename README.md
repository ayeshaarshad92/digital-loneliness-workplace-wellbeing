# digital-loneliness-workplace-wellbeing
Quantitative study on digital loneliness and workplace outcomes in Pakistan's IT industry (SPSS regression, R=0.804)

## Method
- Quantitative, cross-sectional design
- Structured questionnaire, Likert-scale items (n = 52 respondents)
- Sampling: non-probability purposive, IT professionals in Lahore
- Analysis: SPSS regression

## Key Finding
Strong positive relationship between digitalization and 
employee outcomes:
- R = 0.804, R² = 0.647
- F(1, 50) = 91.601, p < 0.001

## Hypotheses Tested
1. Digitalization has a significant positive effect on employee burnout
2. Digitalization has a significant negative effect on job satisfaction
3. Digitalization has a significant negative effect on job performance
